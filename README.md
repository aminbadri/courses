# سامانه محتوای دروس دانشگاهی

## قابلیت‌ها
- ابتدا انتخاب درس
- ورود با رمز اختصاصی همان درس
- صفحه آکادمیک و responsive
- نمایش جلسه‌ها، موضوع و کلیدواژه‌ها
- دکمه PDF و ویدئوی آپارات برای هر جلسه
- جست‌وجوی جلسه و کلیدواژه
- نگهداری ورود در sessionStorage تا پایان نشست مرورگر

## محل ویرایش لینک‌ها
فقط فایل زیر را ویرایش کنید:

`assets/js/course.js`

در آرایه `lessons`:
- `pdf`: لینک مستقیم PDF
- `video`: لینک ویدئوی آپارات
- `keywords`: کلیدواژه‌های استخراج‌شده از PDF
- `topic`: عنوان/موضوع جلسه

مثال:
```js
{
  id: 1,
  title: "جلسه اول",
  topic: "مفاهیم پایه موجودی",
  keywords: ["موجودی", "تقاضا", "هزینه نگهداری"],
  pdf: "https://example.com/session-01.pdf",
  video: "https://www.aparat.com/v/xxxxx"
}
```

## رمز
در ابتدای `assets/js/course.js`:
```js
const PASSWORD = "CHANGE-ME-1234";
```
رمز را عوض کنید.

### هشدار امنیتی
این روش برای «محدودکردن دسترسی معمولی» است، نه حفاظت امنیتی واقعی؛ چون پروژه Static است، رمز داخل JavaScript قابل مشاهده است. اگر حفاظت واقعی لازم باشد، باید معماری server-side یا Password Protection خود Vercel استفاده شود.

## PDFها
در این نسخه PDFها را عمداً داخل GitHub قرار نداده‌ام؛ چون قرار است لینک PDFهای واقعی شما در فیلد `pdf` ثبت شود. اگر PDFها را داخل Repository نگه می‌دارید، مسیر نمونه:
`courses/inventory-control-1/pdfs/session-01.pdf`
